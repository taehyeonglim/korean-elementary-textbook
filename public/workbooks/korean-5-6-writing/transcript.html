첫 글

도서관 자동 대출기의 특징

자동 대출기는 학생이 스스로 책을 빌리고 반납하도록 돕는 기기입니다.

화면의 안내에 따라 학생증과 책의 바코드를 차례로 인식합니다.

대출 결과를 바로 확인할 수 있어 기다리는 시간을 줄입니다.

다만 오류가 나면 사서에게 도움을 요청해야 합니다.

첫 글 확인

  1. 설명 대상은 무엇인가요? 정답: 도서관 자동 대출기
  2. 사용 순서를 쓰세요. 정답: 화면 안내 → 학생증 인식 → 책 바코드 인식 → 결과 확인
  3. 장점은 무엇인가요? 정답: 기다리는 시간을 줄인다.
  4. 주의할 점은 무엇인가요? 정답: 오류가 나면 사서에게 도움을 요청한다.

둘째 글

학교 물병 사용 제안

주장: 학교에서 개인 물병 사용을 늘려야 합니다.

근거 1: 일회용 컵 사용량을 줄일 수 있습니다. 우리 반 일주일 조사에서 일회용 컵 86개가 사용되었습니다.

근거 2: 물을 자주 마시는 습관을 기르는 데 도움이 됩니다.

출처: 6학년 2반 생활 조사표, 2026년 7월.

둘째 글 확인

  1. 글의 주장은 무엇인가요? 정답: 개인 물병 사용을 늘려야 한다.
  2. 수치가 있는 근거는 무엇인가요? 정답: 일주일에 일회용 컵 86개 사용
  3. 근거의 출처는 무엇인가요? 정답: 6학년 2반 생활 조사표
  4. 출처를 밝히는 까닭은 무엇인가요? 정답: 근거의 출처와 신뢰성을 확인하게 하려고

개념 탐구

  1. 설명 글의 내용 선정 기준은 무엇인가요? 정답: 대상의 특성과 독자에게 필요한 정보
  2. 주장 글의 근거는 어떠해야 하나요? 정답: 주장과 관련 있고 믿을 만해야 한다.
  3. 글 전체를 고칠 때 살필 것은 무엇인가요? 정답: 주제의 통일성, 문단 순서, 표현
  4. 공유 전 고려할 것은 무엇인가요? 정답: 독자, 매체, 개인정보, 출처
